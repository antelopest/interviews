### Execution Context

Exectution Context (контекст выполнения) - это среда, где выполняется код. Это контейнер, где JS хранит переменные, функции и this во время выполнения.

**Типы Execution Context:**

* Global Execution Context (создается при старте программы, window - в браузере, this === window).
* Function Execution Context (создается при каждом вызове функции).
* Eval (редко, почти не используется).

Когда создается Execution Context?

В две фазы: Creating Phase и Execution Phase.

1. Creating Phase (создание)
   1. Создается Lexical Environment.
   2. Создается Variable Environment.
   3. Определяется this
   4. Поднимаются переменные и функции (hoisting).
2. Execution Phase (исполнение)
   1. Код выполняется построчно.
   2. Значение присваиваются переменными.

**Структура Execution Context**

```js
{
  LexicalEnvironment, VariableEnvironment, this
}
```

**LexicalEnvironment**

Это объект, который хранит: переменные, функции и ссылка на внешний scope.
